# 《医学图像深度学习可解释性方法的忠实度评估》中文精读讲解

> 英文题目：On the evaluation of deep learning interpretability methods for medical images under the scope of faithfulness
> 作者：Vangelis Lamprou, Athanasios Kallipolitis, Ilias Maglogiannis（希腊比雷埃夫斯大学 数字系统系）
> 期刊：Computer Methods and Programs in Biomedicine 253 (2024) 108238
> 开源代码：https://github.com/vggls/medical_xai

---

## 零、一句话总结

作者在医学图像分类模型上，比较两种经典"热图"解释方法 Grad-CAM 与 HiResCAM，并检验三个量化评估指标（AOPC、Max-Sensitivity、HAAS）能否识别出**真正忠实于模型**的那一个。结论：**AOPC 和 Max-Sensitivity 能识别，HAAS 不能**——HAAS 对医学图像这种"多注意力区域 + 强颜色依赖"的数据失效。

---

## 一、研究问题：为什么这件事值得做

### 1.1 背景
卷积神经网络（CNN）在医学图像上效果很好，但它是"黑箱"。医生和研究者需要知道：模型到底是看了图像的哪些区域才做出这个诊断？这就是**可解释人工智能（XAI）**。

本论文关注其中一类方法——**归因图（attribution map，也叫热图/显著图）**：给一张图，画出一张同样大小的二维图，每个像素值表示"该像素对模型预测这个类别有多重要"。

### 1.2 核心矛盾
归因图方法有一大堆（CAM、Grad-CAM、HiResCAM、Grad-CAM++、Score-CAM……），同一张图用不同方法画出来长得不一样。自然的问题：

- 哪个方法画的热图**真的反映了模型的推理过程**？——这叫**忠实性（faithfulness）**。
- 在缺少标准答案的实际情况里，我们只能用**量化指标**给热图打分。那么，**指标打出来的高分，和"忠实"是不是一回事？**

论文原话的意思：先假设"忠实的方法应该得到更高的指标分数"，然后做实验验证这个假设。

### 1.3 三个贡献
1. 把"识别忠实归因图"作为量化指标的考察维度（以前指标通常只用来比模型/比方法）。
2. 首次把 Max-Sensitivity 和 HAAS 用到医学归因图上。
3. 顺带发现：HAAS 对医学数据有"敏感行为"（在非医学数据上正常，在医学数据上失常）。

---

## 二、背景知识：CAM、Grad-CAM、HiResCAM

### 2.1 CAM（类激活映射）
设模型输入图像为 x，输出 M 个类别的分数 f(x) = (f₁(x), …, f_M(x))。CAM 只适用于特定结构：**Conv - GAP - Class Scores**（卷积层 → 全局平均池化 → 全连接分类层）。

记最后一层卷积的特征图为 A^f（f = 1…F），连接 GAP 层与类别 m 输出分数的权重为 w^f_m，则类别 m 的 CAM 为：

```
A_m^CAM = Σ_f w^f_m · A^f
```

每个特征图整张图乘以一个权重再求和。**关键性质**：这个图所有像素值加起来，恰好等于模型的类别分数（差一个常数）。这正是"忠实"的含义。

缺点：只能用于带 GAP 的网络，且只能解释最后一层卷积。

### 2.2 Grad-CAM
Grad-CAM 把 CAM 推广到任意可微网络、任意卷积层：
1. **梯度平均**：对目标类别分数 s_m 求关于特征图 A^f 的梯度，在空间维度（D₁×D₂ 个像素）上取平均，得到权重 a^f_m：

```
a^f_m = (1 / D₁D₂) · Σ_i Σ_j ∂s_m / ∂A^f_ij
```

2. 加权求和并 ReLU：

```
A_m^Grad-CAM = ReLU( Σ_f a^f_m · A^f )
```

注意：整张特征图**共用一个平均权重**，所以不同像素之间的梯度差异被"抹平"了，热图往往是一大块平滑区域。

### 2.3 HiResCAM
HiResCAM 的唯一改动：用**哈达玛积（逐元素相乘，⊙）**代替梯度平均——每个像素的特征值乘它自己的梯度，不取平均：

```
A_m^HiResCAM = ReLU( Σ_f (∂s_m / ∂A^f) ⊙ A^f )
```

好处：**保留了像素级的梯度信息（包括符号和大小）**，热图分辨率高、边界细。直觉上，它把模型分数"精确地"分解到每个像素上；Grad-CAM 的平均操作则相当于把梯度信息模糊成区域级。

## 三、关键理论：为什么实验要设计成"Conv - Flatten - Class Scores"

这一节（原文 2.2 节 + Table 1）是整篇论文的实验设计基石，务必看懂。

**忠实性的形式化定义**（来自 HiResCAM 原作者 Draelos & Carin）：对类别 m，如果存在只与类别有关的常数 b_m，使得

```
s_m = Σ_{i,j} (A_m)_{i,j} + b_m
```

即"热图所有像素值之和 + 一个偏置 = 模型的类别分数"，则称该归因图**忠实于模型**。它的意思是：热图真的把模型的评分"分解"了，而不是碰巧看起来像。

在此定义下可以证明：

| CNN 结构 | 对最后一层卷积算梯度？ | Grad-CAM vs HiResCAM |
|---|---|---|
| Conv - GAP - Class Scores | 是 | **等价且都忠实**（两者都退化为 CAM） |
| Conv - GAP - Class Scores | 否 | 不等价且都不忠实 |
| Conv - Flatten - Class Scores | **是** | **不等价；只有 HiResCAM 忠实** |
| Conv - Flatten - Class Scores | 否 | 不等价且都不忠实 |
| Conv - GAP/Flatten - Dense - Class Scores | 是 | 不等价且都不忠实 |
| Conv - GAP/Flatten - Dense - Class Scores | 否 | 不等价且都不忠实 |

**这张表怎么读**：只有在"**卷积 → Flatten（展平）→ 分类层**"结构、且对**最后一层卷积**求梯度时，两个方法才会产生不同的热图，并且理论上只有 HiResCAM 是忠实的、Grad-CAM 不是。

这就是全文的"参考设定"（reference setting）：因为"标准答案"已知（HiResCAM 忠实、Grad-CAM 不忠实），所以如果某个指标给 HiResCAM 打的分更高，就说明该指标**能识别忠实性**。在其他所有结构里，要么两者等价，要么两者都不忠实，没法做有意义的比较。

## 四、三个评估指标详解

论文用三个指标给热图打分，**三个指标的"分数越高越好/越低越好"方向不同，别记混**。

### 4.1 AOPC（Area Over the Perturbation Curve，扰动曲线面积）

**直觉**：如果热图是对的，那么把"最重要的区域"遮掉，模型应该立刻不自信（该类概率大幅下降）；遮掉不重要的区域则影响很小。

**做法**：
1. 把热图 A 通过平均池化变成区域级热图 H（如 4×4、8×8、11×11、14×14 个区域）。
2. 按 H 的值从高到低，逐步扰动（本论文用重采样均匀噪声替换像素）最重要的前 k 个区域，得到扰动后的图像 x^(k)。
3. 记录每一步类别概率的下降量，求平均：

```
AOPC = 1/(L+1) · Σ_{k=1..L} [ f(x^(0)) − f(x^(k)) ]
```

其中 f(x^(0)) 是原图概率，f(x^(k)) 是第 k 步扰动后的概率。**AOPC 越大越好**：重要性排名准的热图，会在扰动早期就让概率大幅下降。

### 4.2 Max-Sensitivity（最大敏感度）

**直觉**：一个靠谱的解释方法应该"稳定"——输入图稍微变一点，解释图也应该只变一点点。如果输入几乎没变、解释图却面目全非，就说明该方法不可靠。

**做法**：在原始图像 x 周围、半径 r 的 ℓ∞ 球内采样扰动图像 y，比较解释图之间的差异，取最大者：

```
SENS_MAX = max_{‖x−y‖∞ ≤ r} ‖A(f, x) − A(f, y)‖_F
```

（‖·‖_F 是 Frobenius 范数，即把所有像素差平方求和再开方。）实际用蒙特卡洛采样估计。**Max-Sensitivity 越低越好**。

注意：这个指标严格说衡量的是"解释的鲁棒性/局部稳定性"，并不直接等价于忠实性。但在本论文的设定下，实验发现它恰好能区分忠实与否。

### 4.3 HAAS（Heatmap Assisted Accuracy Score，热图辅助准确率分数）

**直觉**：如果热图真的指出了"模型靠哪些像素做判断"，那么**把这些像素的强度调强**之后，模型应该更容易分对；反之则会帮倒忙。

**做法**：
1. 构造 HA（Heatmap Assisted）图像：把归一化到 [−1, 1] 的图 x_norm 与热图 A_norm 相加（等价于按热图值把像素往正/负方向推）：

```
HA(x, A) = clamp( x_norm · (1 + A_norm), −1, 1 )
```

2. 计算模型在整批 HA 图像上的准确率，与原图准确率之比：

```
HAAS = Accuracy(HA 图像) / Accuracy(原图)
```

**HAAS > 1 表示热图有用**（强化重要特征后模型更准），< 1 表示没用甚至有害。该指标无超参数、计算快，是它的卖点。

## 五、实验设置

### 5.1 四个医学数据集

| 数据集 | 内容 | 规模 |
|---|---|---|
| CRC | 结直肠癌组织病理图像（含 9 类组织） | 107,180 张 |
| Covid-19 Radiography | 胸部 X 光（区分 Covid-19、肺不透明、病毒性肺炎等） | 21,165 张 |
| HAM10000 | 皮肤镜色素性皮损图像（7 类皮肤病变） | 10,015 张（来自 7,470 个独立病灶） |
| BreakHis | 乳腺肿瘤组织病理显微图像（良性/恶性，40X/100X/200X/400X 四种放大倍率） | 2,480 良性 + 5,429 恶性 |

### 5.2 模型与训练
- 用预训练的 **ResNet34、ResNet50、VGG19**（torchvision）微调。
- **关键改造**：把每个网络改成 **Conv - Flatten - Class Scores** 结构——把最后的 GAP 层换成 Flatten，并去掉卷积末尾若干层（不同网络去掉的层不同），从而落入"参考设定"。
- 10 折分层交叉验证；HAM10000 和 BreakHis 额外采用"病灶/组织与训练集独立"的划分，避免数据泄漏偏差。
- 图像统一缩放到 224×224，归一化到 [−1, 1]，用翻转和随机旋转做数据增强。
- 加权交叉熵（处理类别不平衡）+ Adam；早停监控的是**疾病相关类别的平均验证召回率**；各模型超参数见原文 Table 2。
- 归因图用 pytorch-grad-cam 库生成，梯度对最后一层卷积计算（ResNet34：layer4[2].conv2；ResNet50：layer4[2].conv3；VGG19：features[-1]）。

### 5.3 模型性能（原文 Table 3）
用每个数据集上"平衡准确率最接近 10 折均值"的那个模型来做可解释性实验。几个数：

- CRC：ResNet34 平衡准确率 0.889 / AUC 0.993；VGG19 0.94 / 0.992
- Covid-19：ResNet34 0.956 / 0.987；VGG19 0.947 / 0.99
- HAM10000：ResNet50 0.677 / 0.922；VGG19 0.72 / 0.928（类别严重不平衡，可见影响）
- BreakHis：ResNet50 0.859 / 0.943；VGG19 0.84 / 0.919

## 六、实验结果

### 6.1 AOPC（原文 Table 4）——HiResCAM 胜
- 热图划分为 **4×4**（每块区域最大）时，8 个模型里有 7 个是 HiResCAM 分数更高（另 1 个持平）。
- 区域越切越细（8×8、11×11、14×14），HiResCAM 的优势逐渐减弱：8×8 和 11×11 时 6/8 胜，14×14 时 5/8 胜。
- 原文表述 "large sized heatmaps 4×4" 指的是 4×4 网格切出来的**单块区域面积大**，不是网格数量多，读的时候别被绕进去。
- 综合所有热图尺寸，8 个模型里 7 个整体偏向 HiResCAM（唯一例外：Covid-19 数据集上的 VGG19）。
- 例：Covid-19 + ResNet34 + 4×4，HiResCAM 0.73，Grad-CAM 0.69。

### 6.2 Max-Sensitivity（原文 Fig. 3）——HiResCAM 全胜
扰动半径 r 取 0.05～0.5，随半径增大采样数从 20 增到 40。结果：**HiResCAM 在全部 8 个模型、所有半径下分数都更低**，即更稳定。

### 6.3 HAAS（原文 Table 5）——指标失效
- Grad-CAM 的 8 个实验全部 < 1；HiResCAM 除 1 个外也全部 < 1。
- 唯一例外：BreakHis + VGG19 的 HiResCAM = **1.07**（强化热图区域后准确率提升约 7%）。
- 也就是说，HAAS 几乎把所有热图都判为"不合格"，无法区分忠实/不忠实——**在本任务上失效**。

### 6.4 追查 HAAS 失效原因（原文 Table 6）
作者把 HAAS 原文的基准数据集（Cifar-10、STL-10、Imagenette，都是"单一物体、靠形状识别"的类别）拿来，每个数据集训练 **16 个不同超参的 VGG19** 模型，观察 HiResCAM 的 HAAS 范围：

| 数据集 | 最高 HAAS（对应模型 AUC） | 最低 HAAS（对应模型 AUC） |
|---|---|---|
| Cifar-10 | 1.009（0.981） | 0.970（0.969） |
| STL-10 | 1.034（0.966） | 0.978（0.899） |
| Imagenette | 1.002（0.995） | 0.986（0.889） |

非医学数据上，即使是**训练并不完美**的模型，HAAS 也能给出 > 1 的有意义分数；而医学数据上，模型训练得更充分，HAAS 反而大多 < 1。结论：**HAAS 对医学数据更敏感（更容易失真）**，不是模型的问题。

## 七、讨论：作者怎么解释这些结果

### 7.1 为什么 HiResCAM 赢 AOPC 和 Max-Sensitivity
- 差异根源在梯度的用法：Grad-CAM 是**梯度平均**（整张特征图一个权重）→ 注意力区域大而平滑，细节被抹掉；HiResCAM 是**逐像素哈达玛积**→ 保留每个像素梯度的值和符号 → 高分辨率、细粒度、定位更准。
- 反映到指标上：定位准 → 遮住关键区域时概率下降得更早更陡（AOPC 高）；像素级解释稳定 → 小扰动下解释变化小（Max-Sensitivity 低）。
- 原文 Fig. 4 直观展示了这点：两者注意力区域相近，但 Grad-CAM 的区域更大、边界更模糊。

### 7.2 为什么 HAAS 在医学图像上失效
1. **类别结构不同**：基准数据集是"单物体、靠形状区分"（飞机、汽车、鸟……），颜色变化影响小；医学图像往往**多个注意力区域并存、且强依赖颜色/纹理**。
2. **HA 操作可能帮倒忙**：正归因区域被"推亮"，在医学图像里可能破坏颜色/纹理信息，反而混淆模型。原文 Fig. 5A/5B 给了大量例子——HA 图像在关键区域出现明显颜色失真后被分错（如 NORM 正常结肠黏膜、Lung Opacity 肺不透明）。
3. **分布偏移**：HA 变换把像素值推离训练分布。例如热图值 1/2 时，原图 1/2 的像素会变成 3/4，−1/2 变成 −3/4——模型见到的是"没训练过的像素分布"。作者说这点没有深入验证，留作未来工作。

### 7.3 与已有工作的呼应
远程遥感的 Kakogeorgiou & Karantzalos (2021) 在 Grad-CAM 忠实的设定下，观察到 Grad-CAM 的 Max-Sensitivity 和 MoRF 面积最优——与本文结论方向一致。

## 八、结论

1. **AOPC 和 Max-Sensitivity 能识别忠实算法**：在"只有 HiResCAM 忠实"的参考设定下，两者一致地偏向 HiResCAM。原因：HiResCAM 通过哈达玛积保留像素级梯度效应，生成高分辨率、信息量大、鲁棒的映射。
2. **HAAS 不适用于医学归因图比较**：它几乎把所有图判为不准确；对"强颜色依赖、多注意力区域"的复杂医学模式过于敏感。
3. 该工作呼应了遥感领域的结果（AOPC/Max-Sensitivity 能识别忠实算法），并指出"指标与忠实性的关系"仍需逐案例实验，无法给出普适数学结论。

**未来方向**：换别的"忠实/不忠实算法对"、换别的指标、更多数据集和预训练架构。

---

## 九、局限（作者自述）

1. **无法给出通用数学结论**：对任意指标 μ，μ(f, 忠实图) 不必然优于 μ(f, 不忠实图)（无论指标是越大越好还是越小越好），只能做实验。
2. **可比实现太少**：能定制到本文指标的公开实现有限，难以与其他工作定量对比。
3. **计算昂贵**：全部实验在 V100 上完成，无法重复多次做统计检验；用"多组热图尺寸/扰动半径重复实验、结果一致"来弥补；每个数据集只用了"平衡准确率最接近均值"的一个模型。
4. HAAS 的 HA 变换导致分布偏移的问题只提出、未验证。

## 十一、建议的阅读顺序（原文 11 页）

1. **摘要 + 第 1 节结尾的三个贡献**（第 1-2 页）——先知道结论。
2. **2.1 + 2.2 + Table 1**（第 2-3 页）——理解"参考设定"，这是全文的钥匙。
3. **4.2 三个指标的定义**（第 3-4 页）——公式只需知道"输入什么、越大还是越小越好"。
4. **4.4 结果：Table 4、Fig. 3、Table 5、Table 6**（第 4-6 页）——重点看数字方向。
5. **第 5 节讨论 + 第 6 节结论**（第 7-10 页）——看作者如何解释 HiResCAM 胜出、HAAS 失效。
6. 可跳过：3.2 相关工作、4.3 超参数细节、参考文献。

**考试/汇报可用的三句话版**：
- 本文在 Conv-Flatten 结构下比较"忠实的 HiResCAM"与"不忠实的 Grad-CAM"，检验量化指标能否识别忠实性。
- AOPC 与 Max-Sensitivity 在 4 个医学数据集、8 个模型上一致偏向 HiResCAM，说明两者可识别忠实算法。
- HAAS 在医学数据上几乎全部 <1，在非医学基准上正常，说明它对医学图像（多注意力区、强颜色依赖）过度敏感。
